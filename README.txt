NETLIFY:
1. Put index.html and resume.pdf in the same folder.
2. Sign in to Netlify.
3. Use Add new project -> Deploy manually / drag and drop.
4. Drop this folder.
5. Netlify will publish a live *.netlify.app URL.

GITHUB PAGES:
1. Create a public repository named <yourusername>.github.io.
2. Upload index.html and resume.pdf.
3. Enable GitHub Pages from repository Settings -> Pages.
4. Select the publishing branch.
